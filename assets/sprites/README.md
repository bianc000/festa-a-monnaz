### Come sostituire uno sprite:
1. Prendi la tua immagine personalizzata (consigliato formato quadrato, es. 32x32, 64x64 o 128x128 pixel in PNG trasparente).
2. Salvala con il nome esatto del personaggio (es. `leon.png`, `mari.png`, `maya.png`).
3. Sostituisci il file in questa cartella (`assets/sprites/`).
4. Ricarica la pagina del gioco nel browser: il nuovo sprite verrà caricato automaticamente!
